본 서버는 UDP 기반의 신뢰성 전송 프로토콜 Reliable UDP을 구현하고,
Windows 환경에서 고성능 네트워크 처리를 제공하는 IOCP (I/O Completion Port) 모델을 적용한 서버입니다.

일반적인 UDP 통신은 비연결성 + 비신뢰성 특성을 가지며, 패킷 손실, 중복, 순서 역전 문제가 발생합니다.
이를 해결하기 위해 본 서버는 RUDP 전송 계층을 직접 설계하여 다음 기능을 제공합니다:

1.시퀀스 번호 기반 순서 보장

2.ACK 응답 기반 패킷 수신 확인

3.타이머 기반 재전송 (Retransmission)

4.중복 패킷 필터링

5.RTT 기반 전송 지연 조절
